# DemocraciaSint-tica

Scripts de extracción de datos utilizados para el capítulo. Todos los scripts corren con Python 3.10 y fueron ejecutados en sistema operativo Windows.

El Script llamado build deliverables procesa los resultados de la extracción de la API de Twitter y genera las tablas de bases de datos y de análisis.

El Script disclore_patterns analiza los tweets con imágenes con IAG para encontrar lenguaje relacionado con IAG.

El Script extrat_retweets_full extrae todos los retweets de su cuenta original con imágenes y sus variables de interacción, retweeteados por las personas candidatas y de partidos políticos del 1 de julio de 2025 al 31 de enero de 2026.

El Script extrat_tweets_full extrae todos los tweets con imágenes y sus variables de interacción, tweeteados por las personas candidatas y de partidos políticos del 1 de julio de 2025 al 31 de enero de 2026.

Requeriments.txt es un archivo que permite instalar todas las librerías de Python necesarias para correr todos los scripts.

envtemplate es un archivo plantilla que permite insertar el bearer token o ID necesario para acceder a la API V2 de Twitter.
